# ユーザー指定プラン（2026-09-14）

原題：SUNA：砂が動く反転演出と1×1アイコン。

- 元のBlender環境で、モデル・ガラス・砂・照明の質感を維持して反転映像を生成する。
- 準備姿勢から本体を180度回し、カメラと背景を固定したまま持ち上がり・床の反射・接地まで描画する。
- 回転中も重力は下向き。砂が内壁を滑り、崩れて落ちる砂面と粒の動きをベイクし、ガラスに貼り付いた砂を回すだけにしない。
- 約1.25秒、880×1056、24fps、BT.709 H.264。終端は既存の上側全量の落砂映像へ自然につなぐ。準備用静止画も納品する。
- 同じ砂時計から1024×1024の静止画を生成し、既存SUNA本体の1×1アプリアイコンとして採用する。
- アプリの映像全体を回す処理を撤去し、反転専用動画を一度再生してから計測する。
- 永続化しない準備状態を追加し、許可確認→素材準備→反転→予約・計測開始の順を守る。準備中は残り時間を減らさず、連打を防ぐ。
- 再開・復帰・表示切り替えで反転しない。数字表示からの開始では反転完了後に数字表示へ戻す。
- Reduce Motionでは反転を省略。反転中の非アクティブ化で取消。予約開始後は結果を照合して重複を防ぐ。
- 素材・再生・予約の失敗を開始成功にしない。
- 2×2専用ウィジェットの誤った1×1案内を整理し、元の小・中サイズの互換性を戻す。ホーム画面へのアプリアイコン追加手順を載せる。
- 1秒・3分、連打、再開、背景移行、Reduce Motion、各失敗、アイコン起動を検証する。
- 素材を受領・組み込み・検証した後、Releaseビルドを作成してiPhone 14 Pro Maxを更新する。新しい反転素材が届く前に完成と報告しない。

アプリ側の具体的な実装契約は `MAC_INTEGRATION_JA.md` を参照。

ユーザーの追加指示：アプリ側の実装はMac側で行うため、このPCではBlenderの生成だけでよい。
